# WiseRobot Academic Portfolio

A static, Markdown-driven academic website for GitHub Pages.

## Edit content

Open files in `content/`, click the pencil icon, edit the Markdown, and commit. GitHub Pages will publish the updated website automatically.

- `content/profile.md` — name, biography, theme, photo, GitHub and CV links
- `content/research.md` — research interests
- `content/publications.md` — publications, DOI, PDF links
- `content/projects.md` — project cards and images
- `content/contact.md` — contact information

Add images and downloadable PDF documents to `assets/` and use relative paths, such as `assets/paper.pdf`.

## Deployment

GitHub repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `(root)`. Visit https://jade121213.github.io/Template2601/ after deployment.

No server, database, installation, or build step is required. The example profile and publications are fictional sample content.
